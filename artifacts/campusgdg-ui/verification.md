  сохранены для исправления. Исходный пустой URL восстановлен после проверки.
- Список протоколов открывается ArrowDown, Escape закрывает список. Видимый
  клавиатурный фокус: solid, 2.4px, rgb(138,184,250).
- Поиск диалогов без результатов, очистка, переходы между разделами стрелками.
  Создание диалога сбрасывает фильтр. Панель использует родное раскрытие Streamlit.
