Рабочая задача команды CampusGDG: подготовка студенческого AI-агента к демонстрации

Источник постановки: задача GDG Astana CampusPulse AI и запрос команды от 22.10.2026 о передаче файлов, инструментах и выполнимом перепланировании. Это рабочая постановка команды, а не дословная копия задания преподавателя. Проверяемый репозиторий: https://github.com/irrumi/Campusgdg.

Требование 1. В README.md должны быть приведены команды установки зависимостей и запуска пользовательского интерфейса.

Требование 2. В репозитории должен быть MCP-сервер, который регистрирует доступные инструменты агента.

Требование 3. HTTP gateway должен передавать содержимое загруженных файлов в вызов облачного агента. Передача только сообщения, истории и student_context не выполняет это требование.

Требование 4. Инструмент планирования должен принимать занятые интервалы календаря и распределять работу только по свободному времени до дедлайна. Распределения часов по дням без учёта занятых интервалов недостаточно.
