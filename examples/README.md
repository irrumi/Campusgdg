# Example assignment

`assignment.txt` contains two small, independently checkable requirements. Upload
it with the HTTPS URL of a repository you may inspect. It is an educational sample,
not an instruction to publish an Issue or modify that repository.

The application must collect evidence before assessing either requirement. A
repository with only a README can supply documentation evidence, but an absent or
inaccessible CI run remains **unverified**. The deterministic offline tests supply
an explicitly fake failed CI run; that result says nothing about your repository.

Issue proposals require a separate approval for their exact title and body, plus
server-side write configuration. Inspect the selected repository before approving.
